# FALSEBOUND KINGDOM STANDALONE CUTSCENE REMOVER

Mornin!

So in working out how to do some things in the Falsbound Archipelago world I'm working on.... 
I was able to get a cutscene remover to work, and am therefore releasing it to the world as a completed separate thing!

## Requirements

You MUST use a .iso file for this project to work. NOT A NKIT.ISO FILE. There exist apps like NHit 1.4 to convert.

## How to use

1. Ensure python is installed, I used version 3.12 for creation
2. Define your specific options inside of Options.yaml
3. Run Patcher.py and run the outputted patch file
